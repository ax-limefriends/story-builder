# 스토리 빌더

브랜드스크립트(SB7)를 채우면 펀딩 스토리 섹션이 차례대로 채워지고, 제출 전에 점검해 이미지와 텍스트 붙여넣기 순서로 내보내는 단일 HTML 도구입니다. 설치·로그인 없이 브라우저에서만 작동하며, 입력한 글과 사진은 어디에도 전송되지 않습니다.

- 첫 출력 형식: 와디즈 스토리 (화면 관찰값 기준일 2026-10-10)
- 주소: https://mc-jeon.github.io/story-builder/ (Cloudflare 주소는 연결 후 추가)

## 사용 순서

1. **카드**: 아이템, 대상, 저자, 받는 것, 목차, 리워드, 기획전
2. **브랜드스크립트**: 주인공·문제·가이드·계획·실패·성공
3. 상단 **스크립트로 채우기** → 빈 블록에만 들어감
4. **블록**에서 다듬기 (청록 블록은 이미지가 아니라 글로 붙여넣는 블록)
5. **점검** 막힘·주의 해결 → **스토리 내보내기** (이미지 묶음 + `00_붙여넣기_순서.txt`)

## 구조

설정을 세 층으로 나눕니다. 형식을 늘릴 때는 엔진을 두고 설정만 더합니다.

| 층 | 위치 (`docs/index.html`) | 내용 |
|---|---|---|
| 엔진 | 블록 그리기·점검·내보내기 | 공통 |
| 형식 설정 | `FORMATS` | 스토리 폭, 접힘선, 자동 영역, 필수 항목, 숨길 블록. 관찰값은 기준일과 함께 |
| 상품 유형 설정 | `CATS` | 유형별 위험 표현 |

## 0.4 (2026-10-11): 잘 된 와디즈 스토리 10개 기준 보완

모집액·참여자 상위 종료작 10개(전자책·클래스 4, 템플릿 3, 도서 3)의 스토리를 블록 단위로 나눠 본 결과를 반영했습니다. 구조와 패턴만 참고했고, 남의 이미지나 문구는 가져오지 않았습니다.

- **새 블록 13종:** 실적·권위 배지(칸마다 출처), 후기 캡처(큰 인용 + `==형광==` + 동의), 반론 Q&A 말풍선, 번호 특징 01~0N, 미리보기(STEP), 혜택·한정 01~03, 리워드 요약표(구성품 코드 × 리워드), 구성품 상세(A~), 패키지 가격 카드, 이벤트 조건표, 키워드 칩, GIF·영상 자리(이미지로 굽지 않고 순서표에 표시)
- **카드:** 구성품 `코드 | 이름 | 설명`, 리워드 구성은 코드를 `A+B`로 적고 7번째 칸에 "이런 분께". 첫 화면 유형 5가지(실적·약속·질문·마감·희소)를 고르면 대표 이미지 순서를 제안
- **유형별 기본 순서 3종:** 실용 전자책·클래스형, 템플릿·문서형, 도서형. 블록 탭의 "이 순서로 다시 짜기"는 이미 쓴 블록을 같은 역할 자리로 옮김
- **점검 추가:** 첫 화면의 상품 이름, 첫 증거가 접힘선 위에 있는지, 실적 배지·후기의 출처와 동의, 가격 카드의 정가 근거, 같은 문구 3회 반복, 리워드 4개 이상이면 요약표, FAQ 누락, GIF·영상 자리, 보장 표현 확대(역대급·리스크 0·잃을 수 없 등)
