# 스토리 빌더

브랜드스크립트(SB7)를 채우면 펀딩 스토리 섹션이 차례대로 채워지고, 제출 전에 점검해 이미지와 텍스트 붙여넣기 순서로 내보내는 단일 HTML 도구입니다. 설치·로그인 없이 브라우저에서만 작동하며, 입력한 글과 사진은 어디에도 전송되지 않습니다.

- 첫 출력 형식: 와디즈 스토리 (화면 관찰값 기준일 2026-10-10)
- 주소: https://mc-jeon.github.io/story-builder/ (Cloudflare 주소는 연결 후 추가)

## 사용 순서

1. **카드**: 아이템, 대상, 저자, 받는 것, 목차, 리워드, 기획전
2. **브랜드스크립트**: 주인공·문제·가이드·계획·실패·성공
3. 상단 **스크립트로 채우기** → 빈 블록에만 들어감
4. **블록**에서 다듬기 (청록 블록은 이미지가 아니라 글로 붙여넣는 블록)
5. **점검** 막힘·주의 해결 → **스토리 내보내기** (이미지 묶음 + `00_붙여넣기_순서.txt`)

## 구조

설정을 세 층으로 나눕니다. 형식을 늘릴 때는 엔진을 두고 설정만 더합니다.

| 층 | 위치 (`docs/index.html`) | 내용 |
|---|---|---|
| 엔진 | 블록 그리기·점검·내보내기 | 공통 |
| 형식 설정 | `FORMATS` | 스토리 폭, 접힘선, 자동 영역, 필수 항목, 숨길 블록. 관찰값은 기준일과 함께 |
| 상품 유형 설정 | `CATS` | 유형별 위험 표현 |

식품 과정 상세페이지 조립 도구(`mc-jeon/food-detailpage-guide`의 `docs/builder.html`)에서 블록 렌더러·테마·PNG 분할 저장을 가져와 시작했습니다.
